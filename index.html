快捷键与说明

中文输入框里

Alt + ↓把光标后的文字移到下一条开头（光标在最前 = 整条下移）
Alt + ↑把光标前的文字移到上一条末尾（光标在最后 = 整条上移）
Enter确认本条（清除橙色标记）并跳到下一条；需要换行用 Shift+Enter
Ctrl + ↓ / ↑跳到下一条 / 上一条（不清除标记）

任意位置

Alt + N跳到下一个待检查条目（橙色 = 一句中文被自动拆到了多条英文上；黄色 = 匹配把握不大）
Alt + U跳到下一条还没用上的中文（右侧橙底）
Alt + M把当前英文条目与下一条合并（时间轴合并，中英文都拼接）
Alt + S在英文框光标处把当前条目拆分成两条（时间按字数比例分）
Alt + P在视频里播放当前条目（需先载入视频）
Alt + T给当前条目加上/取消“⏱需校时”标记（也可点行内的 ⏱ 或标签本身）
Alt + J跳到下一个需校时的条目
Alt + R给当前条目加上/取消“✎待翻译”手动标记（也可点行内的 ✎译 或标签本身）
Alt + L跳到下一条待翻译的条目（英文独有、没有中文的，以及手动标记的）
Alt + K跳到下一个“对白待审”或“标点待审”条目
Ctrl + Z / Ctrl + Shift + Z撤销 / 重做（文字编辑以“一次进入输入框”为单位）
Ctrl + S按所选格式导出（ASS / SRT）
重新对齐…已有进度时，“自动对齐”按钮会变成“重新对齐…”，点击会先弹窗确认（它会覆盖全部编辑）；对齐后顶部会出现“恢复对齐前的进度”，可以撤回
Ctrl + F / Ctrl + H跳到查找框 / 替换框（查找框里 Enter = 下一处，Shift+Enter = 上一处；替换框里 Enter = 替换当前这处）
F3 / Shift + F3下一处 / 上一处匹配
Alt + G把选中的中文加入专有词汇库（需先在设置里启用）

⏱ 需校时 与 Aegisub

没有音频参考时，有两类条目的时间只是估算：用“拆分英文”切开的两条（按字数比例分时间），以及中文独有的独立条目（中文原时间 + 自动偏移）。它们会一直带着粉色“⏱需校时”标记，按 Enter 确认也不会清除。

• ASS 模板：设置 → ASS → “编辑模板…”。导出时文件头（[Script Info]、样式表）原样照搬模板；中文用第一个样式，中英混排的行写成 中文\N{英文标签}英文，只有英文 / 只有中文的行不加标签。默认是双样式（英文标签 {\rEN}，中文 Default + 英文 EN）；想只换英文字体字号，套用“单样式”预设或把标签改成 {\fnArial\fs44} 之类。也可以直接读取一个你常用的 .ass 文件，样式和英文标签都会照它来。模板存在本浏览器里，所有项目通用。

• 导出 ASS（推荐）：这些行的“说话人(Name)”栏会写上“需校时-拆分 / 需校时-中文独有 / 需校时-手动标记”，字幕正文不受影响。在 Aegisub 里打开后，字幕网格的说话人列一眼可见；也可以用“选择行（Select Lines）”按说话人字段匹配“需校时”一次选中全部。校好后把说话人栏清空即可。中英文用 \N 强制换行，英文另用 EN 样式（字体字号在设置里改）。

• 导出 SRT：可选用 \N 换行；需校时的条目文字前会加 {需校时-…}，导入 Aegisub 后它被当作注释不显示，用查找（Ctrl+F）搜“需校时”即可定位，校完用替换删掉。

待翻译

• 导出待翻译…：把所有待翻译的条目连同前后几条上下文（可调，默认 2 条）整理成一段文本，开头附翻译要求，可复制或下载后直接发给 AI。每行带编辑器里的 #编号，AI 按“#编号 译文”返回，照编号填回即可。上下文可附上已有中文，让 AI 沿用同样的标点和人名译法。

有英文、没有中文的条目会自动显示青色“待翻译”标签（填上中文后自动消失；♪ 歌词行是否算在内可在设置里切换）。导出 ASS 时写在说话人栏（与需校时并存时如“需校时-拆分 待翻译”），导出 SRT 时在文字前加 {待翻译}，方便挑出来交给 AI 翻译。

• 手动标记：有中文但翻译不完整的条目（比如双人对白只翻了一方），按 Alt+R 或点行内的“✎译”按钮标成“✎待翻译·手动”。它和自动的待翻译一样计入统计、能用 Alt+L 跳转、导出时带“待翻译”标记；但编辑中文、按 Enter 都不会清除它，翻好后再按一次 Alt+R 或点标签取消。

中文整理（标点 / 对白破折号）

• 标点：“，”“。”“、”换成一个半角空格；“！？；：”“‘’”「」（）【】～ 等换成对应的英文半角标点；全角字母数字改半角；“——”改成 --；《》没有半角对应，保留。句末多余空格会去掉，“! ? ; :”后面紧跟中文时自动补一个空格。

• 省略号“…”：默认跟随英文——只有这一行英文里也用了 ... 时才改成 ...，否则视同句号换成空格（句末则直接去掉）。也可以在设置里改成“一律 ...”或“一律空格”。

• 双人对白：英文是 - A - B（同一行或分两行）而中文没有对应的“-”时，会按两句的长度比例在空格/句号/问号等处把中文切开，自动补上“-”（格式跟随英文：同行就同行、分行就分行），并标蓝色“对白·已补-”。实在切不开的标红色“对白·缺-”，需手动补。两种都要人工看一眼：按 Alt+K 逐个跳转，确认无误后按 Enter 或点标签清除。导出时也会写进说话人栏 / {…} 标记（“对白待审”）。

• 补 ... ! ? 和引号：英文有 ...、!、? 或双引号而中文没有时，把中英文都按断句（标点、对白“-”、中文字间的空格）切成小段，英文的 ... / 引号落在第几个断句处，就补到中文对应的断句处。例：What? "Nice to meet you, I'm married"? 切成 3 段，中文 怎么? 很高兴认识你 我已婚? 也是 3 段，补成 怎么? "很高兴认识你 我已婚"?。

  – 句首 / 句尾的 ...、句尾的 ! ?（如 …moral code, Phil! → “…道德准则无关!”）、整句被引号包住（或跨条引号的开头 / 结尾）直接补，不打标记。
  – 补在句子中间的标蓝色“标点·已补”，因为中文语序可能和英文不同（如 "Hello," he said ↔ “他说 你好”），请过目。
  – 英文引号不在断句处（如 I watched "Titanic" yesterday）或中文找不到对应位置的，不补，标红色“标点·缺”，手动补上后自动消失。
  – 中文里已有任何引号或书名号《》时不动引号；单引号（容易和 I'm 之类的撇号混淆）不处理；省略号设为“一律当句号 → 空格”时不补 ...。悬停标签可看具体原因，Alt+K 逐个跳转。

• 中文原有换行：一条中文字幕内部的两行合并成一行时，换行处可能是分句（要空格，如“我不知道你想吃什么⏎所以我就买了几个”），也可能是一句话中间折行（不要空格，如“所以你在1986年买下⏎采石场附近那栋房子”）。“智能判断”会综合这些线索打分：下一行是否以“所以/但是/因为/我/你…”开头、上一行是否以“吗/呢/吧…”结尾（→ 空格），上一行是否以“在/把/被/和/给/的…”结尾、下一行是否以“的/了/着/们…”开头（→ 连上），以及英文在对应位置有没有逗号/句号等断句（有 → 空格，整句没断 → 连上）。上一行末尾已有“，”“。”等标点时直接连上（标点会再换成空格）。

• 线索不够明确的换行处会标黄色 ⏎买下|采石 连上 标签，计入“待检查”（Alt+N 逐个跳转）。点标签即可在“连上 / 空格”间切换，确认后按 Enter 清除。设置里也可以改成“一律换成空格”或“保留换行”。

• 这些在“自动对齐”时按设置自动执行；对已有进度，点顶部“整理中文”即可（可撤销）。右侧中文原字幕保持原样，不受影响。

查找替换

顶部常驻查找栏。范围可选中文 / 英文 / 中英；“全词”适合英文单词（如只换 cab 不碰 cabin）；“正则”可用 $1 引用分组。所有匹配会在字幕框里用黄色高亮，当前这处是橙色；跳转时光标留在查找框，可以连续按 Enter。“替换”只换当前这一处，“全部替换”一次换完，都可以 Ctrl+Z 撤销。

专有词汇库（可选，设置里启用）

适合繁中译文转简体后残留的港台译名（如 Steve：“史提夫”→“史蒂夫”）。每个词条记三项：英文原文、繁中译名、简体译名，前两项必填。

• 加入：在英文框里选中原文按 Alt+G，再在中文框（或右侧原字幕）里选中对应译名按 Alt+G，两项齐了自动加入（顺序不限）；也可以在页签上方三个框里手动输入后点“添加”。

• 替换：查到简体译名后填进去，单条“替换”（或在译名框里按 Enter），或“全部替换”所有已填好的。替换只作用于中文；英文原文用来标明是谁 / 哪里，并显示英文、中文各出现几次（英文明显比中文多时，说明可能还有别的译法，可以用顶部查找核对）。点繁中译名可逐个跳到文中。

• 高亮：文中的词条（英文原文和繁中译名）会高亮：紫色 = 还没填简体译名，绿色 = 已填好、等着替换。

• 导入英文名单（IMDb）：在页签里点“导入英文名单”，把 IMDb 演员表粘贴进去，会提取角色名（去掉演员名、集数、DS / DI 等头衔和泛称），拆成单个的名和姓，勾选后放进“待配对英文”。不会改动现有词条，已在词库里的英文自动跳过。点待配对里的名字 → 跳到英文里下一处出现的地方（蓝色下划线标出），英文原文自动填好，再在中文框选中对应译名按 Alt+G 就成了正式词条；再点同一个名字 = 下一处。本集没出现的名字显示为灰色，会留着等以后几集。

• 人名加分隔号：原中文字幕常把全名连着写（如“约翰保罗盖蒂”）。点页签里的“人名加分隔号”，会用词库里的译名（繁中、简体两种都认）找出中文里两个词条紧挨着的地方，弹窗列出要改的行，确认后在中间加分隔号（约翰·保罗·盖蒂）。英文里这几个名字确实连着出现（如 John Paul Getty，在本行附近或本集别处）的默认勾选；英文里没连着出现过的标黄、默认不勾，需要你判断。点预览里的分隔号可单独取消，分隔号样式可选（· / ‧ / ・ / •），可撤销。

• 跨项目：词库不属于某个项目，而是单独保存在本浏览器里，在这个浏览器里打开任何项目都能直接用；替换后词条仍保留，下一集“自动对齐”时会自动替换（可在页签里关掉）。要换浏览器 / 换电脑 / 给不同的剧分别建词库，用“导出词库文件”存成独立的 .json，到那边“导入词库文件”即可（与现有词库合并，同一个繁中译名只保留一条）。“保存项目”的项目文件里也会附带一份当时的词库，打开项目时自动合并进来。

说明

• 自动对齐：先在 ±3 分钟内搜索让中英文字幕“时间重叠最多”的整体偏移，再按每 30 秒为中心、5 分钟窗口做局部微调（可应对中途偏移变化）。之后每条中文按时间重叠分给英文条目；跨两条英文的中文会按标点/空格、依重叠时长比例自动拆开，并标橙待检查。

• 右侧中文原字幕会根据你的编辑结果判断“是否已用上”（附近条目里能找到这段文字即算用上）。如果某条你确实不想要，悬停点“忽略”。

• 视频试看依赖浏览器解码：mp4(H.264/AAC) 基本都行；mkv 在 Chrome/Edge 里常可播放，但 HEVC、AC3/DTS 音轨可能无画面或无声。

• 进度按项目自动缓存在本浏览器里：每对“英文文件名 + 中文文件名”算一个项目，多集可同时保留（最多 50 个，超出时删掉最久没动过的）。点“缓存项目…”可以切换到别的集或删除；切换前当前项目会先存好。换浏览器或清除浏览器数据会丢，重要进度请点“保存项目”存成文件。
